# الموقع الرسمي ثلاثي الأبعاد (3D) — حسن علي الزيات (Hassan Ali Elzayat)

هذا المجلد يحتوي على ملفات الموقع الشخصي الشامل بتصميم عصري ثلاثي الأبعاد (Three.js 3D + Tailwind CSS) للخبير الاستراتيجي **حسن علي الزيات**.

## محتويات الحزمة
1. **`index.html`**: الصفحة الرئيسية للموقع (مرتبطة بملفي `style.css` و `app.js`) — جاهزة للرفع مباشرة على **GitHub Pages** في مستودع `portfolio`.
2. **`style.css`**: ملف التنسيقات والتأثيرات ثلاثية الأبعاد (3D Perspective & Glassmorphism).
3. **`app.js`**: ملف البرمجة التفاعلية ومحرّك الرسوميات ثلاثية الأبعاد (`Three.js WebGL`) وبيانات الخدمات ودراسات الحالة وأداة تخصيص الباقات وأداة التشخيص.
4. **`hassan_elzayat_standalone.html`**: نسخة مدمجة في ملف واحد فقط (تعمل مباشرة بمجرد فتحها في أي متصفح بدون الحاجة لملفات خارجية).

## طريقة التحديث على GitHub Pages (`https://hassanalielzayat.github.io/portfolio/`)
1. افتح مستودع `portfolio` على حسابك في GitHub.
2. ارفع الملفات الثلاثة (`index.html` و `style.css` و `app.js`) في المجلد الرئيسي للمستودع (Root).
3. احفظ التعديلات (Commit changes)، وسيعمل الموقع الجديد تلقائياً على نفس الرابط خلال دقيقة واحدة.
